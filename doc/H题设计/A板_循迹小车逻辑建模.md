## 二、小车运动学模型

### 2.1 差速驱动模型

小车为两轮差速驱动（MG513P-28 × 2），假设无滑动：

```
        ↑ 车头方向(y)
        |
    L───┼───R    L=左轮, R=右轮
        |
        ↓
```

**状态变量**:
- (x, y): 小车中心位置（场地坐标）
- theta: 车头朝向角
- vL, vR: 左右轮线速度
- v: 小车中心线速度 = (vL + vR) / 2
- omega: 角速度 = (vR - vL) / W （W=轮距）

**运动学方程**:
- dx/dt = v * cos(theta)
- dy/dt = v * sin(theta)
- d(theta)/dt = omega = (vR - vL) / W

### 2.2 编码器测速

MG513P-28带霍尔编码器。

- 轮径 r（待确认，估算约3.25cm）
- 减速比 k（MG513P-28通常1:28）
- 编码器PPR P（待确认）

**轮速计算**:
vL = 2*PI*r * nL / k = 2*PI*r * deltaCountL / (P * k * deltaT)

其中 deltaCount 为编码器在 deltaT 内的脉冲计数变化。

### 2.3 场地坐标与路线

```
场地坐标系(白色广告布):
    y↑
     |
  B───────C     AB/CD: 直线1.5m
  ╱         ╲    BC/DA: 半圆弧 r=0.5m
 ╱           ╲   周长≈6.14m
D───────A────→x
```

- A点: 出发/终点，有启停线(5cm黑线+30cm虚线基准)
- 顺时针方向行进
- 路线总周长 ≈ 6.14m

## 三、传感器模型

### 3.1 数字红外循迹阵列

假设使用N路数字红外传感器（N=5或7），横向排列，间距 d。

```
传感器编号:  [0] [1] [2] [3] [4]   (5路示例)
              ←   ←  中心  →  →
```

**每路输出**: 0 = 检测到黑线，1 = 白底（或反之，取决于模块）

**位置偏差计算**（加权法）:
e = sum( wi * si )

其中 wi 为传感器权重（如 [-2,-1,0,+1,+2]），si 为传感器归一化读数。

- e = 0: 小车在线中心
- e > 0: 偏右，需左转
- e < 0: 偏左，需右转

### 3.2 路段识别

通过传感器模式判断当前所在路段：

| 路段 | 传感器特征 | 动作 |
|------|-----------|------|
| 直线(AB/CD) | 中心传感器在线上 | 全速直行 |
| 入弯(BC/DA) | 传感器偏移持续增大 | 减速转向 |
| 弧中 | 传感器持续偏一侧 | 定速转向 |
| 出弯 | 传感器偏移减小 | 加速回正 |
| A点启停线 | 横向5cm黑线垂直于路线 | 检测停车 |

**A点检测**: 启停线是垂直于路线的横向黑线（长5cm），当多个传感器同时检测到黑线时可判断到达A点。

## 四、控制架构

### 4.1 控制层次

```
┌─────────────────────────────────────────┐
│         任务状态机 (最高层)              │
│  启动→循线→弯道处理→停车检测→停止        │
└──────────────┬──────────────────────────┘
               │ 目标速度v_set, 目标朝向
┌──────────────▼──────────────────────────┐
│      循线PD控制器 (中层)                 │
│  输入: 红外偏差e, 当前omega              │
│  输出: 左右轮速差 deltaV (转向量)        │
└──────────────┬──────────────────────────┘
               │ vL_set, vR_set
┌──────────────▼──────────────────────────┐
│    电机速度PID控制器 (底层)              │
│  输入: 编码器实测速度vL/vR, 目标速度      │
│  输出: PWM占空比                         │
└──────────────┬──────────────────────────┘
               │ PWM
┌──────────────▼──────────────────────────┐
│         TB6612 + MG513P-28               │
└─────────────────────────────────────────┘
```

### 4.2 电机速度PID（底层）

每个电机独立速度闭环：

uL = Kp * eL + Ki * integral(eL) + Kd * d(eL)/dt

其中 eL = vL_set - vL_actual，uL 为PWM占空比。

- 采样周期: 10ms (100Hz)
- PWM频率: 10kHz~20kHz
- 编码器读取: 定时器捕获模式或M法/T法测速

### 4.3 循线PD控制器（中层）

deltaV = Kp_line * e + Kd_line * de/dt

左右轮目标速度:
- vL_set = v_set - deltaV
- vR_set = v_set + deltaV

- e: 红外阵列加权偏差
- v_set: 当前路段目标速度（直线快、弯道慢）

### 4.4 速度规划（上层）

根据路段设置不同目标速度：

| 任务 | 路段 | 目标速度 | 理由 |
|------|------|----------|------|
| 第2项(循线≤20s) | 直线 | ~35cm/s | 快速通过 |
| 第2项(循线≤20s) | 弧段 | ~25cm/s | 转向稳定 |
| 第4项(AB≤8s) | 直线AB | ~20cm/s | 球稳定优先 |
| 第5/6项(整圈≤30s) | 直线 | ~22cm/s | 平衡速度与稳定 |
| 第5/6项(整圈≤30s) | 弧段 | ~18cm/s | 减小离心扰动 |

> 加减速使用S型曲线，避免冲击导致钢球偏移。

## 五、任务状态机

### 5.1 状态转移图

```
                    ┌──────────┐
                    │  IDLE    │← 上电初始状态
                    │  等待启动 │
                    └────┬─────┘
                         │ 按键按下
                         ▼
                    ┌──────────┐
                    │  START   │← 发送启动信号给B板
                    │  初始化   │  开始计时
                    └────┬─────┘
                         │
                         ▼
                    ┌──────────┐
            ┌──────│LINE_FOLLOW│──────┐
            │      │  循线行驶  │      │
            │      └──────────┘      │
            │ 检测到入弯         检测到出弯│
            ▼                         ▼
    ┌──────────┐              ┌──────────┐
    │  CURVE   │              │ LINE_    │
    │  弯道处理 │─────────────►│ FOLLOW   │
    │  减速转向 │              │  直线    │
    └──────────┘              └──────────┘
            │                         │
            │        检测到A点        │
            │      (启停线+圈数)      │
            └────────────┬────────────┘
                         ▼
                    ┌──────────┐
                    │  STOP    │← 停车
                    │  计时停止 │  显示总时间
                    └──────────┘
```

### 5.2 状态说明

| 状态 | 入口条件 | 动作 | 出口条件 |
|------|----------|------|----------|
| IDLE | 上电 | 等待按键 | 按键中断 |
| START | 按键按下 | 发B板启动信号、开始计时、OLED显示 | 初始化完成 |
| LINE_FOLLOW | 离开START/出弯 | 全速循线PD控制 | 入弯检测/A点检测 |
| CURVE | 入弯检测 | 减速+增大转向PD | 出弯检测 |
| STOP | A点检测(完成圈数) | 停电机、停止计时、显示时间 | - |

### 5.3 A点停车检测逻辑

**难题**: A点有垂直于路线的5cm黑线，需要区分"经过A点"和"在A点停车"。

**方案**: 圈数计数 + 传感器模式判断

```
A点停车检测逻辑:
1. 启动时圈数计数=0
2. 每次检测到A点横向黑线(多路同时触发) → 圈数+1
3. 第2项任务: 圈数==1时停车
4. 第5/6项任务: 圈数==1时停车

判据:
- 横向黑线: ≥3路传感器同时检测到黑线(区别于循线时的纵向黑线)
- 确认: 连续2-3帧确认，避免误判
- 去抖: 检测到A点后设置冷却时间(如500ms)，避免重复计数
```

### 5.4 任务模式选择

不同测试项的速度和停车策略不同，通过按键长按/短按或上电时配置选择：

| 模式 | 对应任务 | 速度档 | 停车策略 |
|------|----------|--------|----------|
| MODE_1 | 第2项(纯循线≤20s) | 快速档 | 圈数=1时急停 |
| MODE_2 | 第4项(AB段≤8s) | 中速档 | 到B点停车 |
| MODE_3 | 第5项(整圈≤30s) | 中速档 | 圈数=1时停车 |
| MODE_4 | 第6项(任意位置≤30s) | 中速档 | 圈数=1时停车 |

## 六、与B板通信协议

### 6.1 数据帧格式

A板 → B板 (单向，UART有线):

```
帧格式 (共10字节):
┌──────┬──────┬────────┬────────┬────────┬────────┬────────┬──────┬──────┬──────┐
│ 帧头 │ 帧头 │ 速度   │ 速度   │ 加速度 │ 加速度 │ 状态   │ 校验 │ ─    │ 帧尾 │
│ 0xAA │ 0x55 │ 高8位  │ 低8位  │ 高8位  │ 低8位  │ 字节   │ 和   │      │ 0x0D │
└──────┴──────┴────────┴────────┴────────┴────────┴────────┴──────┴──────┴──────┘

状态字节 bit定义:
  bit0: 启动标志(1=已启动)
  bit1: 停止标志(1=已停车)
  bit2: 路段标志(0=直线, 1=弯道)
  bit3: 加减速标志(0=匀速, 1=加速/减速) [待定]
  bit4-7: 保留

速度/加速度: 有符号16位, 单位mm/s和mm/s²
```

### 6.2 发送时机

- 周期发送: 每20ms (50Hz) 发送一次
- 事件发送: 启动/停止/路段切换时立即发送

### 6.3 B板使用场景

B板收到小车运动状态后，用于钢球位置前馈补偿：
- 直线段: 小车匀速，前馈量≈0
- 弯道段: 离心力使球偏移，前馈补偿摆杆角度
- 加减速: 惯性力使球偏移，前馈补偿

## 七、计时与显示

### 7.1 计时逻辑

- 启动按键按下 → 计时开始（SysTick或Timer计数）
- 检测到完成（停车）→ 计时停止
- 分辨率: 1ms
- OLED显示: "Time: XX.XXs"

### 7.2 OLED显示内容（SSD1306 SPI 4线 0.96"）

```
┌────────────────────┐
│  H-TIMER           │ ← 标题
│                    │
│  Time: 18.52s     │ ← 当前/最终时间
│  Lap:  1/1        │ ← 圈数
│  Mode: LINE       │ ← 当前状态
│  Spd:  25cm/s     │ ← 当前速度
└────────────────────┘
```

- SPI 4线: SCK, MOSI, CS, DC (+RES)
- 刷新率: 10Hz (100ms更新一次)

### 8.1 模块接口定义

**ir_sensor.h**:
- `void IR_Init(void)` - 初始化红外GPIO
- `uint8_t IR_ReadAll(void)` - 读取所有传感器，返回位图
- `int8_t IR_GetError(void)` - 返回加权偏差值

**encoder.h**:
- `void Encoder_Init(void)` - 初始化定时器捕获
- `int16_t Encoder_GetCount(uint8_t ch)` - 获取编码器计数值
- `float Encoder_GetSpeed(uint8_t ch)` - 获取轮速(cm/s)

**motor.h**:
- `void Motor_Init(void)` - 初始化TB6612 PWM
- `void Motor_SetSpeed(int8_t left, int8_t right)` - 设置左右电机速度(-100~100)

**pid.h**:
- `void PID_Init(PID_t* pid, float kp, float ki, float kd)` - 初始化PID
- `float PID_Calc(PID_t* pid, float setpoint, float feedback)` - PID计算

**line_follow.h**:
- `void LineFollow_Init(void)` - 初始化循线控制
- `void LineFollow_Process(float v_set)` - 循线处理，输出左右轮目标速度

**state_machine.h**:
- `void SM_Init(void)` - 初始化状态机
- `void SM_Process(void)` - 状态机周期处理(主循环调用)

**uart_comm.h**:
- `void Comm_Init(void)` - 初始化UART
- `void Comm_SendStatus(float speed, float accel, uint8_t state)` - 发送状态给B板

## 九、主循环时序

```
主循环 (1ms周期, 基于SysTick):

  时间槽      任务                    频率
  ─────────────────────────────────────
  0-1ms      红外读取               1000Hz (每ms)
  0-1ms      编码器读取              1000Hz
  1-2ms      电机速度PID             1000Hz
  2-3ms      循线PD控制              1000Hz
  3-4ms      状态机处理              1000Hz
  每10ms     OLED刷新               100Hz
  每20ms     UART发送B板             50Hz
  每100ms    速度规划更新             10Hz
```

> 使用定时器中断保证控制周期精确，主循环做非实时任务。
