# H题 - 车载平衡滚球运动控制系统：任务详解与约束分析

> 来源: 2026年全国大学生电子设计竞赛赛区赛(TI杯) H题原文
> 分析日期: 2026-07-29

---

## 一、系统组成

车载平衡滚球运动控制系统由以下四部分组成：

| 部件 | 说明 |
|------|------|
| 小车 | 轮式驱动循线小车，车载电池供电 |
| 带凹槽的摆杆 | 25cm PPR水管改造，槽内放钢球 |
| 摆杆控制机构 | 控制摆杆角度，进而控制钢球位置 |
| 钢球 | 直径约1cm，在凹槽内滚动 |

**机械结构关系**：摆杆左端用铰链或合页固定（距小车平板高度 h≥5cm），另一端连接摆杆角度控制机构。通过改变摆杆倾角，控制钢球在凹槽内的滚动位置。

---

## 二、场地规格

### 2.1 场地尺寸

- 材质：白色广告布喷绘
- 环形路线：黑色线
- 线宽：**1.8±0.2 cm**

### 2.2 路线几何

```
        B ────────────── C        AB段: 直线 1.5m
       ╱                   ╲       CD段: 直线 1.5m
      ╱    半圆弧 r=0.5m    ╲      BC段: 半圆弧 r=0.5m
     ╱                       ╲     DA段: 半圆弧 r=0.5m
    D ───────────────────── A
            1.5m
```

- A、B、C、D 四点设定
- AB段、CD段：直线，各长 **1.5米**
- BC段、DA段：半圆弧，半径 **0.5米**
- **路线总周长** = 2×1.5 + 2×π×0.5 ≈ **3 + 3.14 = 6.14米**
- 测试中**允许自带场地**

### 2.3 启停点A

- A点有黑色启停线：长 **5cm**，线宽 1.8±0.2cm，与环路垂直、居中
- 启停线沿中心轴线绘制停车基准虚线：宽 **0.1cm**，长 **30cm**
- 用于判断小车停车位置偏差

## 三、尺寸与器件限制（硬性约束）

### 3.1 车身尺寸

| 约束项 | 限制值 |
|--------|--------|
| 车身长度 | **≤ 35 cm** |
| 车身宽度 | **≤ 25 cm** |
| 驱动方式 | 轮式驱动 |
| 供电 | 车载电池 |
| 摆杆 | 整个摆杆不超出车身 |

> 车身面积上限：35×25 = 875 cm²，摆杆25cm长度可以放入

### 3.2 测试基准位置

- 需在小车**中心轴线**上指定**唯一测试位置**
- 全程以此位置判断到达/起始偏差
- 停车偏差 = 测试位置与基准线（点）间的绝对距离

### 3.3 循迹模块限制

- **只能使用红外光电模块**
- 数量不限
- 禁止使用摄像头循迹、磁导航等其他方式

### 3.4 显示装置

- 必须有启动按键和显示装置
- 显示屏尺寸 **≤ 2英寸**
- 须安装在方便观测的位置
- 按键启动时计时开始并显示时间

### 3.5 摆杆规格（严格规定）

| 参数 | 规定值 |
|------|--------|
| 材质 | 4分PPR水管改造 |
| 长度 | **25 cm** |
| 外径 | **2 cm** |
| 壁厚 | **0.34 cm** |
| 截面外圆弧半径 | 约 **1 cm** |
| 截面内圆弧半径 | 约 **0.65 cm** |
| 铰链固定端距平板高度 h | **≥ 5 cm** |
| 钢球直径 | 约 **1 cm** |

**摆杆改造要求**：
- 摆杆整体要求**平直**
- 凹槽内壁表面**光滑，保持原状**
- 钢球可灵活在凹槽中滚动
- 若内壁有凹坑或做任何增摩擦改造 → **不予测试**
- 刻度线贴在凹槽剖面**边沿上**（**不允许贴在凹槽内**）
- 刻度间距 **0.1 cm**（1mm）
- **凹槽内钢球位置检测必须采用摄像头**

### 3.6 图传装置约束

| 约束项 | 要求 |
|--------|------|
| 发送模块 | 稳固安装于车体 |
| 摄像头位置 | 固定在摆杆凹槽上方 |
| 画面要求 | 覆盖整个摆杆，完整清晰看到钢球滚动轨迹并能判定位置 |
| 接收模块 | 置于环形线路以外 |
| 接收端显示存储 | PAD/笔记本电脑等 |
| 功能 | 实时显示 + 完整记录视频 + 能按要求回放 |
| 封存 | 比赛结束后接收模块及显示存储装置与作品一起封存 |

### 3.7 运行约束

- 行驶过程中**不得人为干涉、遥控**小车运动
- 小车的**投影必须在轨迹线上**
- 投影**完全脱离轨迹线** → 本次测试**失败**
- 行驶过程中**不得停车**（循线任务中）

## 四、任务要求与评分（逐项详解）

### 第1项：摆球位置监测图传装置（6分）

**要求**：安装图传装置（发送+接收），能稳定实时显示钢球在凹槽中滚动的画面，完整记录每次测试视频且能按要求回放。

**得分要点**：画面稳定、清晰、完整覆盖摆杆、可回放。

---

### 第2项：循线行驶一圈（16分）

**要求**：
- 小车置于A点，按键启动
- 沿黑线**顺时针**行驶一圈并停到A点
- 计时停止并显示行驶总时间
- 行驶总时间 **≤ 20s**
- 停车偏差 **≤ 2cm**

**速度分析**：
- 周长 ≈ 6.14m，时间 ≤ 20s
- **平均速度 ≥ 0.307 m/s**（约 30.7 cm/s）
- 需要在直线段加速、半圆弧段适当减速

---

### 第3项：静态摆杆控制（13分）

**要求**：
- 小车**静止状态**
- 摆杆控制装置控制小球从中心点O → +5cm处 → 折返 → -5cm处并稳定
- 运行时间 **≤ 5s**
- ±5cm处的最大误差绝对值 **≤ 1cm**

**控制分析**：
- 球移动范围：±5cm（总行程约15cm: 0→+5→-5）
- 球杆系统位置控制，需快速响应+稳定无超调
- 时间5s内完成3段运动，单段约1.5s

---

### 第4项：AB段行驶+球稳定（20分）

**要求**：
- 小车置于A点，钢球置于中心点O
- 按键启动，沿黑线顺时针行驶并通过B位置
- AB间行驶时间 **≤ 8s**
- 行驶过程中钢球须稳定在摆杆中心点附近
- 误差绝对值 **≤ 1cm**

**速度分析**：
- AB段 = 1.5m直线，时间 ≤ 8s
- **平均速度 ≥ 0.1875 m/s**（约 18.75 cm/s）
- 直线段相对简单，但加减速时钢球受惯性力影响

---

### 第5项：整圈行驶+球稳定（20分）

**要求**：
- 小车置于A点，钢球置于中心点O
- 按键启动，沿黑线顺时针行驶一圈并通过A位置
- 整圈行驶总时间 **≤ 30s**
- 钢球须稳定在摆杆中心点附近
- 误差绝对值 **≤ 1cm**

**速度分析**：
- 周长 ≈ 6.14m，时间 ≤ 30s
- **平均速度 ≥ 0.205 m/s**（约 20.5 cm/s）
- **难点**：半圆弧段转弯时离心力+小车方向变化对钢球的扰动

---

### 第6项：任意位置球稳定（20分）

**要求**：
- 小车置于A点，钢球置于摆杆**任意指定位置**
- 按键启动，沿黑线顺时针行驶一圈并通过A位置
- 整圈行驶总时间 **≤ 30s**
- 钢球能稳定在摆杆上的**任意指定位置**附近
- 误差绝对值 **≤ 1cm**

**控制分析**：
- 非中心点稳定，摆杆需保持非零倾角补偿重力分量
- 不同目标位置对应不同平衡角度，控制更具挑战
- 需要位置伺服+角度前馈的组合控制

---

## 五、评分汇总与得分策略

| 项目 | 分值 | 难度 | 得分策略 |

| 第1项 图传装置 | 6 | 低 | 基础分，模块化即可完成 |

| 第3项 静态球控制 | 13 | 中 | 基础分，球杆PID参数调试 |
| 第4项 AB段+球稳定 | 20 | 高 | 提高分，直线段耦合较小 |
| 第5项 整圈+球稳定 | 20 | 高 | 提高分，弯道扰动是关键 |
