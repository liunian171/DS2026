**注意 - BluePill→ZET6引脚差异（需修改.ioc和代码）：**
| 功能 | 原分配(BluePill参考) | ZET6实物(PB3缺失/PA9冲突) |
|------|---------------------|--------------------------|
| 电机PWM | TIM1_CH1/CH2 (PA8/PA9) | → **TIM8_CH1/CH2 (PC6/PC7)** |
| 红外循迹 | PB3, PB4, PB5, PB6, PB7 | → **PB4, PB5, PB6, PB7, PB8, PB9** |
| 调试串口 | 无 | → **USART1 (PA9/PA10, USB_TTL)** |

**已实现功能 (当前代码, 基于旧引脚):**
- HSE+PLL 72MHz时钟
- 5路红外传感器循迹PD控制 (PB3-PB7) ⚠️ PB3不可用
- 双电机速度PID闭环 (TB6612+编码器13ppr)
- SSD1306 OLED计时显示 (I2C 0x3C)
- 任务状态机 (IDLE→按键启动→巡线→A点检测停车)
- A点检测 (5路全黑+500ms防抖+圈数计数)
- 电机PWM (TIM1 PA8/PA9) ⚠️ PA9与USB_TTL冲突
- USART2 UART (115200, 预留B板通信)

**待实现/待修改:**
- [ ] **适配ZET6实物引脚** (改.ioc: TIM1→TIM8, PB3→PB9)
- [ ] A→B板UART运动状态通信协议
- [ ] 多任务模式选择 (不同速度/圈数)
- [ ] S型速度规划
