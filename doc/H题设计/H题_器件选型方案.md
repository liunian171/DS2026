## 二、TMC2209国产紫板规格（关键）

### 2.1 模块类型确认

用户使用的是 **TMC2209国产紫板**，**不支持串口通讯**（资料明确注明），仅支持 **STEP/DIR脉冲控制**。

### 2.2 关键引脚（紫板）

| 引脚 | 功能 |
|------|------|
| **EN** | 使能输入，低电平正常工作 |
| **MS1/MS2/MS3** | 细分选择输入 |
| **NC** | 悬空 |
| **CLK** | CLK输入，使用内部时钟请接地 |
| **STEP** | STEP脉冲输入（STM32产生脉冲） |
| **DIR** | 方向控制信号输入 |
| **VM** | 电机电源正极（接12V） |
| **M1B/M1A/M2A/M2B** | 电机绕组1/2控制引脚 |
| **VIO** | 逻辑电源正极（3.3V/5V） |

### 2.3 细分设置（紫板 MS1/MS2/MS3）

| MS3 | MS2 | MS1 | 细分 |
|-----|-----|-----|------|
| GND | GND | GND | 1 |
| GND | VCC | VCC | 8 |
| VCC | GND | GND | 32 |
| VCC | VCC | VCC | 16 |

完整8种细分见TMC2209手册。**推荐细分：8细分或16细分**。
- 17PM步进电机1.8°步距角
- 8细分=0.225°/脉冲，16细分=0.1125°/脉冲
- 摆杆25cm，1cm球位置对应角度≈2.3°，精度足够

### 2.4 关键参数

- MAX输出电流: 2A
- 推荐工作电流: MAX 1.7A
- 负载驱动电压范围: 5.5~38V
- IC逻辑工作电压: 3.3V/5V
- 模块尺寸: 21mm × 15mm

### 2.5 STM32 F4控制方案

由于紫板**不支持串口通讯**，仅能用 **STEP/DIR脉冲控制**：

```
STM32 F4                TMC2209紫板
┌──────────┐            ┌──────────┐
│ TIMx_CH1 ├─STEP脉冲──►│ STEP     │
│ GPIO     ├─DIR方向────►│ DIR      │
│ GPIO     ├─使能EN─────►│ EN       │
│ 3.3V     ├─────────────►│ VIO      │
│ GND      ├─────────────►│ GND      │
│ (12V锂电)├────VM──────►│ VM       │
└──────────┘            │ M1A/M1B  ├─► 17PM电机
                        │ M2A/M2B  │
                        └──────────┘
```

**STM32定时器配置**：
- PWM模式产生STEP脉冲，频率=步进速率
- DIR通过GPIO控制高低电平
- 用**定时器计数**精确控制脉冲数（即位置闭环）
- 用**加减速曲线**控制脉冲频率，避免失步

**17PM步进电机控制参数估算**：
- 17PM常见规格: 1.8°步距角，12V 0.4A，扭矩约0.4N·m
- 摆杆+钢球总重约60g，重心12.5cm处，所需扭矩0.074N·m
- 17PM扭矩足够，无需减速机构（直驱）

## 三、ESP32-CAM + OV3660 规格（关键）

### 3.1 硬件配置

| 项目 | 规格 |
|------|------|
| **主控** | ESP32 (内置Wi-Fi + 蓝牙) |
| **图像传感器** | OV3660 (CMOS) |
| **模块尺寸** | 27mm × 40.5mm × 4.5mm |
| **工作电压** | 5V |
| **深度睡眠电流** | 最低6mA |

### 3.2 OV3660支持的分辨率

| 分辨率 | 像素 | 推荐 |
|--------|------|------|
| QXGA | 2048×1564 | ❌ 帧率太低 |
| **CIF（默认）** | **400×296** | ✅ **推荐** |
| QVGA | 320×240 | ✅ 帧率高 |

> **推荐分辨率：CIF (400×296)**，平衡清晰度和帧率(10-20fps)。

### 3.3 默认固件即用

ESP32-CAM出厂自带默认固件：
- 上电自动创建Wi-Fi热点（名称以"ESP32"开头）
- 连接热点后浏览器访问 `192.168.4.1` 进入控制页面
- 实时视频流：`http://192.168.4.1:81/stream` (MJPEG格式)
- 单帧拍照：`http://192.168.4.1/capture?_cb=时间戳`

### 3.4 本方案图传方案（手机接收）

**操作流程**：
1. ESP32-CAM上电 → 创建WiFi热点
2. 手机连接该热点
3. 手机浏览器访问 `192.168.4.1:81/stream` 看实时画面
4. 手机自带录屏功能录制（Q16确认无需车载SD卡）
5. 视频回放时手动操作

**注意事项**：
- 官方Q14确认**现场不提供WiFi**，ESP32-CAM作为AP热点，手机连接即可
- 官方Q14确认**ESP32-CAM热点设备赛后需封箱**（在车上）
- 官方Q61: 同频干扰自行解决，可考虑固定信道
- 官方Q62: 测试期间**仅允许图传工作**，测试前关闭其他无线模块

## 四、计时显示屏安装位置

**赛题原文规定**：
> "小车必须有启动按键和**显示装置**，按键启动时计时系统开始计时并显示时间，显示屏尺寸不大于 2 英寸，**且须安装在方便观测的位置**。"

**官方Q5确认**：
> "不限；**只针对计时显示**。"

**结论**：
- ✅ **计时显示屏必须装在小车上**（车载），≤2英寸
- ✅ 位置"方便观测"即可，没有更具体位置限制
- ✅ 其他调试屏幕**不受≤2英寸限制**，可装独立大屏

**建议位置**：车顶或车尾上方，屏幕朝上或朝后，方便评委观测。

### 5.2 A板（循迹主控）职责

```
A板 STM32 F4 — 循迹小车控制
┌──────────────────────────────────────────────┐
│  输入                    输出                  │
│  ├── 数字红外循迹(5-7路)  ├── 左电机PWM(TB6612)│
│  ├── 编码器A/B(2路)      ├── 右电机PWM(TB6612)│
│  ├── 启动按键(GPIO中断)   ├── 电机方向(4×GPIO) │
│  └── 电池电压(ADC)       ├── OLED显示(SPI)    │
│                          ├── B板通信(UART)    │
│                          └── 状态LED(GPIO)    │
└──────────────────────────────────────────────┘

核心任务:
1. 红外循迹PD控制(直线+弯道)
2. 电机速度闭环PID(编码器反馈)
3. 速度规划(S型加减速)
4. A点停车检测(圈数+横向黑线)
5. 计时与OLED显示
6. 向B板发送运动状态(速度/加速度/弯道标志)
```

### 5.3 B板（摆杆控制主控）职责

```
B板 STM32 F4 — 摆杆滚球控制
┌──────────────────────────────────────────────┐
│  输入                    输出                  │
│  ├── K230D球位置(UART)   ├── STEP脉冲(TMC2209)│
│  ├── A板运动状态(UART)   ├── DIR方向(GPIO)    │
│  └── (可选)角度反馈(ADC) ├── EN使能(GPIO)     │
│                          └── 状态LED(GPIO)    │
└──────────────────────────────────────────────┘

核心任务:
1. 接收K230D钢球位置坐标(UART)
2. 球杆系统PID/LQR控制算法
3. 17PM步进电机角度控制(STEP/DIR脉冲)
4. 接收A板运动状态做前馈补偿
5. 加减速曲线控制(避免失步)
```

### 5.4 A板→B板通信（UART有线）

```
帧格式 (10字节):
┌──────┬──────┬────────┬────────┬────────┬────────┬────────┬──────┬──────┬──────┐
│ 0xAA │ 0x55 │ 速度高  │ 速度低  │ 加速高  │ 加速低  │ 状态   │ 校验 │ ─    │ 0x0D │
└──────┴──────┴────────┴────────┴────────┴────────┴────────┴──────┴──────┴──────┘

状态字节: bit0=启动 bit1=停止 bit2=弯道 bit3=加减速
速度/加速度: 有符号16位, mm/s, mm/s²
发送频率: 50Hz (20ms周期)
```

## 八、关键风险

### 8.1 摆杆改造（不可逆风险）
- PPR水管开槽必须平直光滑，有凹坑或增摩擦改造**不予测试**
- 官方Q65: **不允许任何改造**

### 8.2 无线通信限制
- 官方Q62: 测试期间**仅允许图传工作**，MCU间必须有线UART
- 测试前必须关闭调试用的其他无线模块

### 8.3 钢球脱落即失败
- 官方Q50: 钢球脱落即判定本次失败
- 需确保全程球不脱出（Q60允许加防滚挡片）

### 8.4 步进电机失步
- TMC2209紫板**默认无串口通讯**，无法读取运行状态
- 高加减速或负载突变时可能失步，导致位置误差
- 缓解：合理加减速曲线、控制加速度、避免突然负载变化

### 8.5 全程误差考察
- 官方Q37: 考察全程，过渡过程不能超差
- 需控制超调（PID微分项、串级控制）

### 8.6 双摄像头布局
- K230D(GC2093) + ESP32-CAM(OV3660)都需固定在凹槽上方
- 需合理布局避免互相遮挡
