# UNO R3球衡杆原型映射表

> 日期：2026-07-31  
> 目的：先在UNO R3完成视觉外环、x42S脉冲位置链路和调参接口，再迁移到RM F427。  
> 约束：不采用现有PID整定文档的控制结论或增益，只使用用户确认正确的系统参数。

## 一、当前串级闭环

```text
目标位置 r（UNO保存）
        |
K230D -> 相对中心O的位置x、帧号、状态
        |
UNO: e=r-x -> 位置外环PID -> 目标梁角（±10°）
        |
UNO: 梁角×传动比换算 -> STEP/DIR脉冲位置规划
        |
x42S: 内部编码器 + Emm FOC电机位置闭环 -> 齿轮齿条 -> 梁
```

当前不使用AS5600，所以UNO不能直接测量实际梁角；累计脉冲只能估算命令角，齿隙、打滑和机构柔性不可观测。

## 三、冻结接口

K230D发送ASCII行：

```text
B,<frame_id>,<position_mm>,<state>\n
```

- `position_mm`：相对梁中心O，正右负左。
- `state`：0 LOST、1 VERIFY、2 TRACK、3 HOLD。
- 只有TRACK帧更新PID；LOST立即命令回水平；最后有效TRACK帧超过200 ms未更新也回水平。
- 现有K230代码已改为4字段；UNO解析器暂时保留旧7字段兼容，方便回退排查。

## 四、UNO引脚与启动

| 引脚 | 功能 |
|---|---|
| D2 | 人工调平确认按键，`INPUT_PULLUP`，按键接GND |
| D5 | x42S EN；上电保持高阻，因EN有效电平仍待实物确认 |
| D6 | x42S STEP |
| D7 | x42S DIR |
| D8 | K230D TX → UNO SoftwareSerial RX（38400） |
| D9 | SoftwareSerial占位TX，不连接K230D |

PID增益、脉冲速率、加速度和`DIRSIGN`默认均未配置；人工调平按D2后，还需通过115200 USB串口逐项设置，满足全部安全门后`ARM`才会成功。

方向测试命令为`JOG+`（D7=HIGH）和`JOG-`（D7=LOW）：每次16脉冲、100 pulse/s，累计限制为零位±160脉冲（约±0.52°梁角）。执行过JOG后必须重新人工调平并按D2，否则程序拒绝ARM。

## 五、角度脉冲换算

已确认传动比为电机角到梁角`0.02885`。按x42S默认16细分、200整步/转：

```text
3200 pulse / 电机转
梁角/脉冲 = (360° / 3200) × 0.02885 = 0.003245625°
脉冲/梁角度 ≈ 308.106
±10° ≈ ±3081 pulse
```

该换算必须在确认x42S实际细分后才能用于实物。旧TMC2209的1/8细分数据不适用。

## 六、验证状态

- K230D脚本：4字段发送修改后通过Python AST语法检查；未在K230D实机运行。
