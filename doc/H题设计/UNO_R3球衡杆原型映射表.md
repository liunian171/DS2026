## 一、当前串级闭环

```text
目标位置 r（UNO保存）
        |
K230D -> 相对中心O的位置x、帧号、状态
        |
UNO: e=r-x -> 位置外环PID -> 有符号脉冲速率
        |
UNO: D3输出PUL/STEP，D2给出DIR，累计命令位置执行非对称硬限位
        |
x42S: 内部编码器 + Emm FOC电机位置闭环 -> 齿轮齿条 -> 梁
```

当前不使用AS5600，所以UNO不能直接测量实际梁角；累计脉冲只能表示命令电机轴角。X42S内部编码器能闭合电机轴，但齿隙、打滑和机构柔性仍不可观测。

## 三、冻结接口

K230D发送ASCII行：

```text
B,<frame_id>,<position_mm>,<state>\n
```

- `position_mm`：相对梁中心O，正右负左。
- `state`：0 LOST、1 VERIFY、2 TRACK、3 HOLD。
- 只有TRACK帧更新PID；LOST立即命令回水平；最后有效TRACK帧超过200 ms未更新也回水平。
- 当前`k230_try.py`已核对为4字段发送；新UNO解析器只按本4字段协议从零实现，不复用已弃用旧解析器。
- K230D当前使用UART2、38400、8N1，物理Pin 11为TX、Pin 12为备用RX；当前Pin 11未接UNO。Windows只读枚举UNO为COM9，另一候选设备为`OpenMV Cam USB COM Port (COM7)`，但当前`B,...`帧只写物理UART2，双USB连接不会自动形成控制数据通道。

## 五、角度脉冲换算（标准脉冲模式的待实物确认换算）

### 当前PID机械硬限位

用户确认：以手动调平点为零位，顺时针最多2/3圈、逆时针最多1/3圈，超过可能影响水管。依据已确认的3200脉冲/圈，为确保整数脉冲不越界，新控制代码采用：

```text
顺时针命令位置上限 = +2133 pulse
逆时针命令位置下限 = -1066 pulse
```

该限位依据UNO累计发出的命令脉冲，并非X42S实际编码器位置反馈；当前脉冲方向接口不能向UNO返回实际位置。

已确认传动比为电机角到梁角`0.02885`。按x42S默认16细分、200整步/转：

```text
3200 pulse / 电机转
梁角/脉冲 = (360° / 3200) × 0.02885 = 0.003245625°
脉冲/梁角度 ≈ 308.106
±10° ≈ ±3081 pulse
```

该换算只在x42S配置为标准`PUL/STEP + DIR`闭环脉冲输入、实际为1.8°电机和16细分时成立。当前需读取实物菜单后才能用于代码；它不适用于`PUL_WID`模式。旧TMC2209的1/8细分数据同样不适用。
