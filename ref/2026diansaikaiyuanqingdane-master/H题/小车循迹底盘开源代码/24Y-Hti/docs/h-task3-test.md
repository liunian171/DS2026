# H 题第 3 问实车测试

目标路线：A → C → 右侧黑色半圆弧 → B → D → 左侧黑色半圆弧 → A，运动时间不超过 40 s。

## 几何与初始姿态

- A-C、B-D 对角线长度均约为 1281 mm。
- 对角线与水平切线夹角约为 38.66°。
- 起点 A 的左右轮轴线中点对准 A，车头必须直接朝向 C。

## 控制阶段

1. `DIAGONAL_AC`：陀螺仪/编码器闭环直行约 1240 mm，为 C 点前向枢轴预留约 42 mm。
2. `ALIGN_C`：仅外侧轮前进，左转约 38.66°，对准 C 点圆弧切线。
3. `ACQUIRE_C`：预测左转并搜索右侧半圆黑线。
4. `ARC_CB`：沿黑线左转约 180°到 B。
5. `ALIGN_B`：仅外侧轮前进，左转约 38.66°，对准 B-D。
6. `DIAGONAL_BD`：闭环直行到 D；约 1244 mm 的阶段目标包含 B 点枢轴位移，并为 D 点枢轴预留空间。
7. `ALIGN_D`：仅外侧轮前进，右转约 38.66°，对准 D 点圆弧切线。
8. `ACQUIRE_D`：预测右转并搜索左侧半圆黑线。
9. `ARC_DA`：沿黑线右转约 180°到 A，末端丢线后依靠陀螺仪补足转角。
10. `STOPPING`：在 A 点停车，理论车头方向为水平向右。

直线最高速度 220 mm/s，弧线速度 180 mm/s，总流程超时 38 s。

## OpenOCD 阶段值

- `g_h_task_phase`：1=AC，2=C姿态，3=搜索C，4=CB，5=B姿态，6=BD，7=D姿态，8=搜索D，9=DA，10=停车。
- 通过条件：`g_h_task_number = 3`、`g_h_task_finished = 1`、`g_pi_fault_code = 0`。

故障码：1 堵转，2 轮速异常，3 总超时，4 循迹串口失联，5 未找到或提前丢失弧线，6 陀螺仪失联。
