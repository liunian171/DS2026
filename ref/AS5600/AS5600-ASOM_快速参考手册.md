# AS5600-ASOM 磁旋转位置传感器 快速参考手册

> 来源：立创商城数据手册 + AMS OSRAM 官方 datasheet v1.06  
> 适用型号：AS5600-ASOM（I2C + PWM 输出）

---

## 一、芯片概述

| 参数 | 规格 |
|------|------|
| 功能 | 12位可编程非接触式磁性旋转位置传感器 |
| 分辨率 | 12位（0.087° / LSB） |
| 输出方式 | 模拟电压 / PWM / I2C数字接口 |
| 角度范围 | 默认 0°~360°，可编程 18°~360° |
| 工作电压 | 1.7V ~ 5.5V |
| 工作电流 | 典型 < 2.5mA（活动模式），支持自动低功耗 |
| 封装 | SOIC-8 |
| I2C地址 | **固定 0x36**（不可更改，同一总线只能挂一个） |
| 通信速率 | Standard-mode(100kHz) / Fast-mode(400kHz) / Fast-mode Plus(1MHz) |

**注意**：AS5600 的 I2C 地址固定为 `0x36`，无法通过软件或硬件配置更改。同一 I2C 总线上只能连接一个 AS5600。

## 二、引脚定义（SOIC-8）

| 引脚 | 名称 | 类型 | 功能说明 |
|------|------|------|----------|
| 1 | VDD5V | 电源 | 5V 供电输入（使用内部 LDO） |
| 2 | VDD3V3 | 电源 | 3.3V 供电输入（直接供电时与 VDD5V 短接） |
| 3 | OUT | 输出 | 模拟电压 / PWM 输出 |
| 4 | GND | 电源 | 地 |
| 5 | PGO | 输入 | 编程选项引脚（内部上拉，接 GND = 编程选项 B） |
| 6 | SDA | I/O | I2C 数据线（开漏，需外部上拉） |
| 7 | SCL | 输入 | I2C 时钟线（开漏，需外部上拉） |
| 8 | DIR | 输入 | 旋转方向极性选择（GND=顺时针增加，VDD=逆时针增加） |

### 供电方式

- **5V 模式**：VDD5V 接 4.5~5.5V，VDD3V3 接 1μF 电容到地（内部 LDO 输出）
- **3.3V 模式**：VDD5V 和 VDD3V3 短接，接 3.0~3.6V（OTP 编程需 3.3~3.5V）

## 三、I2C 接口

### 基本参数

| 参数 | 值 |
|------|-----|
| 从机地址 | `0x36`（7位） |
| 写地址 | `0x6C` |
| 读地址 | `0x6D` |
| 最大 SCL 频率 | 1 MHz（Fast-mode Plus） |
| 数据格式 | MSB 优先 |

### 支持的 I2C 操作

- 随机/顺序读取（Random/Sequential read）
- 字节/页写入（Byte/Page write）
- **ANGLE / RAW ANGLE / MAGNITUDE 寄存器自动递增抑制**：读取这些寄存器后，地址指针不会自动递增，方便重复读取同一寄存器

### I2C 读写时序要点

- 数据在 SCL 上升沿采样
- 从机每接收 1 字节后发送 ACK
- 主机读取最后一个字节后不发送 ACK（NACK），然后发送 STOP

## 四、寄存器映射

### 只读寄存器（状态/数据）

| 地址 | 名称 | 位宽 | 说明 |
|------|------|------|------|
| `0x00` | ZMCO | 2位 | OTP 烧写计数器（ZPOS/MPOS 已烧写次数） |
| `0x0B` | STATUS | 8位 | 状态寄存器（见下方详解） |
| `0x0C` | RAW ANGLE H | 4位 | 原始角度高字节（bits[11:8]） |
| `0x0D` | RAW ANGLE L | 8位 | 原始角度低字节（bits[7:0]） |
| `0x0E` | ANGLE H | 4位 | 滤波后角度高字节（bits[11:8]） |
| `0x0F` | ANGLE L | 8位 | 滤波后角度低字节（bits[7:0]） |
| `0x1A` | AGC | 8位 | 自动增益控制值（5V: 0~255；3.3V: 0~128） |
| `0x1B` | MAGNITUDE H | 4位 | 磁场幅度高字节 |
| `0x1C` | MAGNITUDE L | 8位 | 磁场幅度低字节 |

### 可读写寄存器（配置）

| 地址 | 名称 | 位宽 | 说明 |
|------|------|------|------|
| `0x01` | ZPOS H | 4位 | 零位（起始位置）高字节 |
| `0x02` | ZPOS L | 8位 | 零位（起始位置）低字节 |
| `0x03` | MPOS H | 4位 | 最大位置高字节 |
| `0x04` | MPOS L | 8位 | 最大位置低字节 |
| `0x05` | MANG H | 4位 | 最大角度范围高字节（替代 MPOS） |
| `0x06` | MANG L | 8位 | 最大角度范围低字节 |
| `0x07` | CONF H | 6位 | 配置寄存器高字节（bits[13:8]） |
| `0x08` | CONF L | 8位 | 配置寄存器低字节（bits[7:0]） |
| `0xFF` | — | — | 命令寄存器（烧写命令） |

### 无效地址行为

- 读取无效地址：返回全 0，地址指针仍递增
- 写入无效地址：不 ACK，但地址指针仍递增

## 五、STATUS 状态寄存器（0x0B）

| 位 | 名称 | 说明 |
|----|------|------|
| bit 5 | MD | **磁铁检测标志**（1=检测到磁铁，0=未检测到） |
| bit 4 | ML | 磁铁太弱（AGC 达到最大增益溢出） |
| bit 3 | MH | 磁铁太强（AGC 达到最小增益溢出） |

**重要**：读取角度前务必先检查 `MD = 1`，确保磁铁在位且磁场强度正常。

---

## 六、CONF 配置寄存器（0x07~0x08）

CONF 是 14 位寄存器，控制芯片的核心行为。上电默认值全为 0。

### 位域定义

```
CONF[13:0] = {SF[1:0], FTH[2:0], WD, PWMF[1:0], OUTS[1:0], HYST[1:0], PM[1:0]}

地址 0x07 (CONF H): bits[13:8] = {SF[1:0], FTH[2:0], WD}
地址 0x08 (CONF L): bits[7:0]  = {PWMF[1:0], OUTS[1:0], HYST[1:0], PM[1:0]}
```

### 各字段详解

#### 1. PM[1:0] — 电源模式（bits[1:0]，低字节）

| PM[1:0] | 模式 | 说明 |
|---------|------|------|
| 00 | Normal | 正常模式（默认） |
| 01 | LPM1 | 低功耗模式 1 |
| 10 | LPM2 | 低功耗模式 2 |
| 11 | LPM3 | 最低功耗模式 |

#### 2. HYST[1:0] — 迟滞（bits[3:2]，低字节）

| HYST[1:0] | 迟滞带 |
|-----------|--------|
| 00 | 关闭（默认） |
| 01 | ±1 LSB（±0.044°） |
| 10 | ±2 LSB（±0.088°） |
| 11 | ±3 LSB（±0.132°） |

**建议**：一般应用建议设为 `01`（1 LSB），可消除静止时的输出抖动。

#### 3. OUTS[1:0] — 输出模式选择（bits[5:4]，低字节）

| OUTS[1:0] | 输出模式 |
|-----------|----------|
| 00 | 模拟输出 — 全范围（默认，10%~90% VDD） |
| 01 | 模拟输出 — 缩减范围（10%~90% VDD 映射到编程子范围） |
| 10 | **PWM 输出** |
| 11 | 保留（不要使用） |

**注意**：
- 默认上电为模拟输出模式
- 如需 PWM 输出，必须通过 I2C 将 OUTS 设为 `10`
- 如仅使用 I2C 读取角度，建议将 OUTS 设为 `00` 以避免 OUT 引脚意外负载

#### 4. PWMF[1:0] — PWM 频率（bits[7:6]，低字节）

| PWMF[1:0] | PWM 频率 |
|-----------|----------|
| 00 | 115 Hz（默认） |
| 01 | 230 Hz |
| 10 | 460 Hz |
| 11 | 920 Hz |

#### 5. WD — 看门狗（bit 8，高字节）

| WD | 说明 |
|----|------|
| 0 | 关闭（默认） |
| 1 | 启用自动低功耗模式（I2C 通信后自动进入低功耗） |

#### 6. FTH[2:0] — 快速滤波器阈值（bits[11:9]，高字节）

| FTH[2:0] | 慢速→快速阈值 | 快速→慢速阈值 |
|----------|---------------|---------------|
| 000 | 仅慢速滤波器（默认） | — |
| 001 | 6 LSB | 1 LSB |
| 010 | 7 LSB | 1 LSB |
| 011 | 9 LSB | 1 LSB |
| 100 | 18 LSB | 2 LSB |
| 101 | 21 LSB | 2 LSB |
| 110 | 24 LSB | 2 LSB |
| 111 | 10 LSB | 4 LSB |

#### 7. SF[1:0] — 慢速滤波器（bits[13:12]，高字节）

| SF[1:0] | 延迟 | 最大 RMS 噪声 |
|---------|------|---------------|
| 00 | 2.2 ms | 0.015° |
| 01 | 1.1 ms | 0.021° |
| 10 | 0.55 ms | 0.030° |
| 11 | 0.286 ms | 0.043° |

## 七、PWM 输出模式

### 信号结构

- 每个 PWM 帧 = **4351 个 PWM 时钟周期**
- 帧结构：128 高电平周期 + 4095 数据周期 + 128 低电平周期
- 占空比与角度成正比
- 0° = 128 高 + 4223 低
- 最大角度 = 4223 高 + 128 低

### 角度计算公式

```
角度 = (高电平周期数 - 128) / 4095 × 编程角度范围
```

或简化为：

```
角度 = (占空比%) / 100 × 编程角度范围
```

### 配置步骤

1. 通过 I2C 写 CONF 寄存器：`OUTS = 10`，`PWMF` 选择所需频率
2. OUT 引脚输出 PWM 信号
3. 主机通过输入捕获测量占空比，换算为角度

---

## 八、模拟输出模式

### 默认配置（OUTS = 00）

- 输出电压范围：GND ~ VDD（全范围）
- 12 位 DAC 分辨率
- 角度与电压成线性比例关系

### 缩减范围配置（OUTS = 01）

- 输出电压范围：10% VDD ~ 90% VDD
- 映射到编程的 ZPOS~MPOS 子范围

### 输出步数计算

```
N = (θ_max / 360) × 4096
```

其中 θ_max 为编程的最大角度范围。

## 九、角度读取（I2C）

### 读取滤波后角度（推荐）

```c
// 寄存器地址
#define AS5600_ADDR     0x36
#define REG_ANGLE_H     0x0E
#define REG_ANGLE_L     0x0F

// 读取 12 位角度值
uint16_t read_angle() {
    uint8_t high, low;

    // 写寄存器地址
    Wire.beginTransmission(AS5600_ADDR);
    Wire.write(REG_ANGLE_H);
    Wire.endTransmission(false);  // 重复起始

    // 读取 2 字节
    Wire.requestFrom(AS5600_ADDR, 2);
    high = Wire.read();  // bits[11:8] 在 low nibble
    low  = Wire.read();  // bits[7:0]

    return ((high & 0x0F) << 8) | low;  // 组装 12 位值
}

// 换算为角度（0~360°）
float angle_deg = (read_angle() / 4096.0) * 360.0;
```

### 读取原始角度（低延迟）

```c
#define REG_RAW_ANGLE_H  0x0C
#define REG_RAW_ANGLE_L  0x0D
// 读取方式同上，地址改为 0x0C/0x0D
```

### 读取状态寄存器

```c
#define REG_STATUS      0x0B

uint8_t read_status() {
    Wire.beginTransmission(AS5600_ADDR);
    Wire.write(REG_STATUS);
    Wire.endTransmission(false);
    Wire.requestFrom(AS5600_ADDR, 1);
    return Wire.read();
}

// 检查磁铁检测
bool magnet_detected() {
    return (read_status() & 0x20) != 0;  // bit 5 (MD)
}
```

## 十、角度范围编程（ZPOS / MPOS）

对于不需要完整 0°~360° 的应用，可以通过编程 ZPOS（零位）和 MPOS（最大位置）来定义自定义角度范围，从而提高输出分辨率。

### 编程要求

- 角度范围必须 **> 18°**
- 必须通过 I2C 接口操作
- 可选择写入 OTP 永久保存（最多 3 次）或仅写入寄存器（掉电丢失）

### 编程步骤（选项 A：通过 I2C）

```
1. 上电 AS5600
2. 将磁铁转到起始位置（零位）
3. 读取 RAW ANGLE 寄存器（0x0C~0x0D）
4. 将读到的值写入 ZPOS 寄存器（0x01~0x02），等待 ≥1ms
5. 按 DIR 定义的方向旋转磁铁到停止位置（旋转量 > 18°）
6. 读取 RAW ANGLE 寄存器
7. 将读到的值写入 MPOS 寄存器（0x03~0x04），等待 ≥1ms
8. （可选）执行 BURN_ANGLE 命令永久烧写
```

### 使用 MANG 替代 MPOS

也可以直接写入 MANG 寄存器（0x05~0x06）指定角度范围大小，而非停止位置。

**注意**：MANG 只能在 ZPOS 和 MPOS 从未被 OTP 烧写过（ZMCO = 00）时写入。

## 十一、OTP 烧写（永久保存配置）

### 烧写命令

| 命令 | 写入 0xFF 的值 | 作用 | 限制 |
|------|---------------|------|------|
| BURN_ANGLE | `0x80` | 永久烧写 ZPOS 和 MPOS | 最多 3 次；需 MD=1 |
| BURN_SETTING | `0x40` | 永久烧写 MANG 和 CONF | 只能 1 次；需 ZMCO=00 才能烧 MANG |

### 烧写验证

烧写后，依次向 0xFF 写入 `0x01`、`0x11`、`0x10` 加载 OTP 内容，然后读取对应寄存器验证。

### OTP 烧写注意事项

- 3.3V 模式下，VDD3V3 引脚需接 **10μF 电容** 到地（仅编程时需要）
- 每次寄存器命令后，新设置至少 **1ms** 后在输出端生效
- 强烈建议烧写后进行功能测试
- 供电线源阻抗不应超过 0.5Ω

## 十二、AGC 与磁场诊断

### AGC 寄存器（0x1A）

- 5V 模式：范围 0~255
- 3.3V 模式：范围 0~128
- **最佳值应在范围中间**（5V: ~128；3.3V: ~64）
- 值接近 0：磁场太强（MH=1）
- 值接近最大：磁场太弱（ML=1）

### 磁铁安装建议

- 气隙范围：0.5~3mm
- 使用径向磁化（diametric magnetized）的圆柱形磁铁
- 磁铁中心应与芯片封装中心对齐

## 十四、常见问题速查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| I2C 无法通信 | 地址错误 / 无上拉电阻 | 确认地址 0x36；SDA/SCL 接 4.7kΩ 上拉到 VDD |
| 角度读数跳变 | 迟滞未开启 / 磁场不稳定 | 设置 HYST=01；检查磁铁气隙和对中 |
| PWM 无输出 | OUTS 未配置 / PGO 接地冲突 | 写 CONF 使 OUTS=10；检查 PGO 引脚状态 |
| AGC 值接近 0 或最大 | 磁铁太强/太弱 | 调整气隙；更换合适强度的磁铁 |
| 烧写失败 | 电压不足 / 已超次数 | 确保 3.3~3.5V 编程电压；检查 ZMCO 计数 |
| 输出方向相反 | DIR 引脚接反 | 将 DIR 引脚换接到 GND 或 VDD |

## 十五、关键公式汇总

```
角度值（12位）= (高字节 & 0x0F) << 8 | 低字节
角度（度）    = 角度值 / 4096 × 360°
模拟输出步数  = (θ_max / 360) × 4096
PWM 占空比    = (高电平周期 - 128) / 4095 × 100%
```
