# BallBeam_UNO 平台映射表

## 当前系统职责

| 模块 | 已确认职责 | 当前实现状态 |
|---|---|---|
| Arduino UNO R3 | D3输出`PWM/STEP`，D2输出`DIR`；通过COM9接收电脑转发的K230D帧和调参命令，运行外环 | 三参数自动固件已烧录并实机ARM；200 pulse/s命令计数正常，实物MStep=16，但电机轴几乎不转；等待X42S输入脉冲/位置诊断 |
| X42S（Emm 固件） | 累计脉冲目标，以内部磁编码器反馈运行电机轴闭环；可通过独立通信端口提供状态 | 闭环职责已由资料确认，实物菜单值待确认 |
| K230D | 计算球相对中心的位置并将严格4字段帧同时写入UART2和USB控制台 | USB镜像已写入当前脚本，AST通过，实机输出待验证 |
| 电脑桥接 | 过滤K230D USB日志，只把合法`B,...`帧和用户调参命令转发到UNO | Python桥接已实现，10项协议/转发测试通过；COM7/COM9实测待进行 |
| 球杆控制 | UNO视觉PID输出有符号脉冲速率；X42S内部编码器完成电机轴位置内环 | 软件编译通过，台架闭环待验证 |

## 分层映射

| 层次 | UNO 侧 | X42S 侧 | 进入条件 |
|---|---|---|---|
| 运动物理层 | D3产生计数脉冲；D2给出方向；当前不配置EN | 脉冲端口接收目标增量 | 最新测试接线已确认；实际接收行为待整圈测试 |
| 可选遥测层 | UART/RS485只读查询、超时和响应校验 | 返回实际位置、误差和状态 | 用户决定是否加入后实施 |
| 执行层 | 脉冲计数、频率、方向、限幅和停止的安全封装 | 内部编码器+Emm FOC电机轴闭环 | R04运动参数经确认并验证 |
| 感知层 | COM9接收电脑过滤后的K230D位置差；仅TRACK有效 | 不参与 | 软件已实现，端口实测后验收 |
| 控制层 | 外环PID、加速度限制、非对称位置硬限位、失效回零 | 执行动作；当前无回读 | 软件已实现，必须分阶段实测后ARM |

旧 STEP/DIR 源码和 D5/D6/D7 诊断映射不进入当前实现。当前只采用用户最新给出的 D2=`DIR`、D3=`PWM/STEP`。X42S内部闭环只测量电机轴，不能测量齿轮齿条之后的实际球杆角度。
