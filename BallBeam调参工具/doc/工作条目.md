# BallBeam_UNO 工作条目

## 重新开发总目标

使用 Arduino UNO R3 输出 `PUL/STEP` 脉冲列和独立 `DIR` 电平驱动 X42S，由 X42S 内部编码器和 Emm 固件完成电机轴闭环。先确认实际脉冲模式和安全动作，再接入 K230D 位置差，最后实现视觉外环到 X42S 电机位置内环的串级控制。UART/RS485 仅作为可选只读遥测，是否加入等待确认。

## 已确认输入

- 用户最新说明：当前由 UNO R3 输出脉冲波和独立方向电平控制电机，不使用通信控制运动。
- X42S 的电机轴闭环由驱动板内部编码器和 Emm 固件完成；UNO 不需要外接该编码器来形成电机轴闭环。
- 位置量 `0–65535` 对应一圈 `0–360°`，换算为 `角度 = 位置值 × 360 / 65536`。
- 方向符号 `00/01` 分别表示输入脉冲数的正/负号。
- 默认 16 细分时，3200 个输入脉冲对应一圈 360°。
- 后续 K230D 只需传相对目标的位置差。
- 手动调平后按键确认，失效策略回到水平；这些需求在相应控制条目开始时重新核对接口细节。
- 2026-08-01 最新测试接线：UNO D2 为方向引脚，D3 为 PWM/STEP 引脚。
- 2026-08-01 用户读取实物菜单：`P_Pul=PUL_ENA`、`CtrlMode=CR_VFOC`、`En=HOLD`、`MStep=16`；厂商资料定义`HOLD`为一直使能，实物每圈脉冲数确认为3200。
- 当前K230D源码使用UART2、38400、8N1，从物理Pin 11（TX）发送 `B,<frame_id>,<position_mm>,<state>\n`，并把同一严格帧镜像到USB；位置为相对中心毫米，`0 mm`是中心，状态2为TRACK。
- 用户确认机械动作不得超过手动调平点顺时针2/3圈、逆时针1/3圈；按3200脉冲/圈保守换算为顺时针最大+2133脉冲、逆时针最小-1066脉冲。
- PID初值不采用项目内PID整定文档的结论；参数需集中在源码顶部，并通过K230D实时位置数据分阶段实测调节。
- 2026-08-01用户要求后续只输入`KP/KI/KD`三个参数，UNO依据位置误差符号自动决定运动方向并持续保持中心。R10固定使用已实际动作过的`SIGN=+1`、`RATE=200`、`ACCEL=400`、`RETURNRATE=200`和`DEADBAND=5`；这些是当前执行配置，不是X42S规格。

## R02 已确认输入及后续选项

- 当前一圈测试使用已确认的 D2=`DIR`、D3=`PWM/STEP`；实物`En=HOLD`一直使能，当前程序不输出EN。
- `MStep=16`，因此每圈3200脉冲、每脉冲0.1125°。
- 是否增加 UART/RS485 只读遥测仍属R05后续选项；若需要，再确认接口和引脚。

## R07/R08 已确认与尚待确认的输入

- 用户确认采用电脑桥接：保持双USB，由电脑程序接收K230D USB控制帧、过滤后转发给UNO。
- Windows当前枚举UNO为COM9、K230D为COM7；COM7已用严格`B,...`帧和CanMV状态栏双重确认。COM号仍可能随插拔变化。
- `/sdcard/main.py`已通过板级复位确认自启动；COM7在115200和12M两种主机配置下各3秒读取到114/115个严格帧，说明当前USB CDC链路两者均可读，桥接程序继续使用已冻结的115200默认值。
- 电脑桥接实测转发282帧并在UNO端更新帧号；UNO全程LOCKED且pulse=0。一次`ERR invalid_vision_frame`原因未确认，已进入调试记录，后续TRACK复测时统计是否复现。
- 球位于中心右侧（`position_mm>0`）时，首次校正应让电机顺时针还是逆时针；该控制极性将通过受限小动作和K230D数据实测，不从结构朝向推测。
- 用户确认当前不需要物理按键；手动调平后使用电脑桥接控制台命令`ZERO`确认零位。
- 首次闭环前需由现场操作者在K230启动提示的60帧背景采集期移走钢珠，随后放回并确认`vision_state=2`。2026-08-01已完成该流程；放回后6秒228帧全部TRACK，位置稳定为-112 mm，视觉前置门已通过。

## 已发现但未解决的资料冲突

- MODBUS 手册给出的速度范围上限与原厂自由协议示例注释不一致（3000 RPM 与 5000 RPM）。首次运动参数不得据此自行选定，须在后续条目中确认或实测。
- V1.0.5 手册的标准脉冲菜单和 V2.0.2 更新记录新增的 `PUL_WID` 并存；独立 `DIR` 更符合标准脉冲方向接口，但仍必须以实物菜单值确认。
