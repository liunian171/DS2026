## 三、使用流程（start_ballbeam_tune.bat）
1. **手动调平摆杆**（水平）——启动时自动复位UNO，**当前姿态=零点**，必须水平
2. 双击 `start_ballbeam_tune.bat`（确保K230D已在运行，球不在轨道上）
3. 窗口出现 `[CMD] >` 后，**把钢球放到轨道左端**
4. 自动进入闭环（`AUTO ARMED`），随时输入命令调参
5. 结束时输入 `quit`（自动DISARM）或 `DISARM`

## 三、命令表（回车即生效）

| 命令 | 作用 | 实测建议 |
|---|---|---|
| `PID 10 2 10` | 改 KP KI KD | KP 10~15，KI 0~2，KD 10~30 |
| `RATE 2000` | 最大脉冲速率 (pulse/s) | 2000~8000，固件上限12000 |
| `ACCEL 40000` | 脉冲加速度 (pulse/s²) | 8000~50000 |
| `RETURNRATE 1000` | 回零速率 | 默认1000 |
| `DEADBAND 5` | 死区 (mm) | 默认5 |
| `SIGN 1` / `SIGN -1` | 控制方向 | 已验证 SIGN=1 正确 |
| `STATUS` | 查看当前状态（默认不刷屏） | 每输入一次显示一条 |
| `RETURN` | 命令位置回零（杆回水平） | 也可用于验证电机是否执行 |
| `DISARM` | 锁定电机输出 | 安全停止 |
| `quit` | 退出桥接（自动DISARM） | 安全退出 |

## 四、状态字段说明（STATUS输出）

```
mode=ARMED zero=1 auto=1 frame=101765 pos_mm=-105 vision_state=2 track_age_ms=10
req_hz=1533.66 current_hz=2000.00 pulse=1351 target=1780 kp=15.0000 ki=2.0000 kd=10.0000
sign=1 rate=2000.0 accel=8000.0 return_rate=1000.0
```

| 字段 | 含义 |
|---|---|
| mode | LOCKED/ARMED/RETURNING |
| zero | 零点是否有效（1=有效） |
| pos_mm | **球位置误差（mm，相对轨道中心O，负=左，正=右）**——调参主依据 |
| vision_state | 0=丢失 1=确认 2=跟踪 3=保持 |
| track_age_ms | 距上次有效跟踪的时间（>200ms注意丢球） |
| req_hz / current_hz | PID请求速率/实际脉冲速率 |
| pulse | UNO命令脉冲累计（软件计数，非编码器反馈） |
| target | 位置式控制的目标脉冲位置（±2200=杆±8°限幅） |

## 五、关键参数（已实测确认，勿随意改）

| 参数 | 值 | 依据 |
|---|---|---|
| 细分 | 16 | 实物菜单 MStep=16 |
| 脉冲/圈 | 3200（电机轴） | 16细分，0.1125°/脉冲 |
| **传动比** | **31.2:1**（电机1圈=摆杆11.5°） | 实测：电机1圈→齿条端升5cm，力臂25cm |
| 杆角/脉冲 | 0.0036°/脉冲 | 0.1125/31.2 |
| 软限位 | ±2200脉冲（杆±8°） | 控制限幅，防球高速飞出 |
| 机械限位 | ±30°（±8300脉冲） | 结构件卡住，勿到达 |
| 球静摩擦 | 需杆角4~10°才滚动 | 球卡死是主要难题 |

## 六、调试结论与注意（2026-08-01实测）

1. **方向**：SIGN=1 已验证正确（球在负侧→正向推→球向0移动）
2. **电机执行**：命令脉冲增长但球不动时，先查：X42S是否插电 → 是否堵转保护触发（断电重启恢复）→ 接线接触
3. **堵转保护**：X42S默认使能（转速<8RPM且电流>2200mA持续2秒→关电机）。球卡死压杆会触发，**需断电重启X42S恢复**；建议有条件时在X42S菜单关闭堵转保护
4. **振荡不收敛**：当前纯反馈PID在"球静摩擦死区+光滑管道"下难以收敛（实测KP/KD多组组合均为±100mm极限环）。已改**位置式控制**（PID输出积分成目标脉冲位置target，杆限速跟随），限幅±2200
5. **零点规则**：UNO复位瞬间=零点，启动前必须手动调平；复位由 `--reset-uno` 的DTR脉冲实现
6. **丢球行为**：视觉丢失时UNO保持最后输出（未改归零逻辑），注意球滚出ROI/端点时数据异常
7. **实时调参**：所有命令即时生效，无需重启（PID命令会重置积分/微分状态）
